      How to read a repository in two minutes

      1. Start with README.md. It says what the project does and how to run it.
      2. Find the entry point. Look in src/ for a file like main or App, then follow its imports.
      3. Check the tests. A tests/ folder shows what the author considers important to keep working.
      4. Look at the automation. .github/workflows/ shows how the project is checked and shipped.
