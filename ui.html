Skills are easy to list. This page runs them.

Sign-in sessions, role checks, validation, error recovery, state and responsive layouts are working code on this page, written in HTML, CSS, TypeScript and React, with the Angular equivalents beside them. Try each one, then read the code behind it.

Try the live demo Read the source code

  • Authentication

    Sign in against a simulated server. Sessions expire, renew and end cleanly, and the token stays in memory, never in localStorage.

  • Authorization

    Roles decide what the screen offers and what the API accepts. A viewer who skips the button still gets a 403.

  • Validation

    Fields check on blur and on submit, errors are announced, focus lands on the first problem, and the server re-checks every payload.

  • Security

    Untrusted text is escaped or sanitized against an allow-list, links are limited to https, and sign-in resists guessing.

  • Error handling

    Timeouts, retries with backoff, typed errors and an error boundary. Failures say what happened and what to do next.

  • State management

    One reducer owns the data. Updates show instantly and roll back if the request fails, and the live state is on screen.

  • Responsive UI

    The table responds to its container, not just the screen. Drag its corner and watch it turn into cards.

  • Angular

    A route guard, an HTTP interceptor, a signal store and typed forms, written the Angular way and compiled with the strict Angular compiler.

The demo's server is simulated inside the page, so sign-in, permissions and failures behave like a real API with no network calls. The Angular files pass the strict compiler, but they are source only and do not run on this page.
